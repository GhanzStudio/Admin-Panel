📘 Panduan Setup Supabase & Hosting ke GitHub Pages

Langkah 1: Setup Supabase Database

  1. Buka https://supabase.com dan buat akun / project gratis.
  2. Di menu Project Settings > API, salin Project URL dan anon / public key.
  3. Di menu SQL Editor, buat tabel contoh seperti users, products, atau orders.
  4. Pastikan Row Level Security (RLS) mengizinkan SELECT/INSERT untuk anonim atau konfigurasi policy sesuai kebutuhan.

Langkah 2: Deploy ke GitHub Pages

  1. Buat repositori baru di GitHub (misal: admin-dashboard).
  2. Unggah 3 file berikut ke root repositori:
    • index.html
    • style.css
    • app.js
  3. Buka Settings > Pages pada repositori GitHub Anda.
  4. Pada bagian Build and deployment > Source, pilih Deploy from a branch, pilih branch main (atau master) dan folder / (root), lalu klik Save.
  5. Website dashboard phpMyAdmin Anda akan aktif di https://username.github.io/admin-dashboard/ dalam 1-2 menit!
